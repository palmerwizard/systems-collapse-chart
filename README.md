A beam labeled THE STAGED SHOW, resting on twelve pillars. The twelve are the systems that manipulate symbols — and the systems slated for automation.

## The twelve pillars

Each system runs on literal glyphs — letters, numbers, marks — and deploys those glyphs as meaning, used as a weapon. Open a pillar on the chart to see both layers, the named mechanism doing the work, and where the system stands.

| Pillar | The symbol layer | The mechanism |
|---|---|---|
| Psychological | DSM codes, diagnostic labels | The therapy loop with no done-criterion; labels that eject |
| Financial | Digits, balances, credit scores | Value as database rows; reading-system dependency |
| Law | Seals, signatures, docket numbers | Process as toll gate; the better ledger wins |
| Health | Rx, ICD codes, chart abbreviations | Deferred maintenance of the body; managed symptoms, billable indefinitely |
| Education | Letter grades A–F, credentials | The "good enough to pass" trap; stalling education |
| Media / Information | Headlines, counts, checkmarks | The authorless operation; the directed flood |
| Housing | Addresses, unit numbers, lease clauses | Deferred maintenance as profit |
| Labor | Titles, badges, employee IDs | Face-saving jobs |
| Food | Label stamps, claims, barcodes | Engineered inputs behind marketing language |
| Community | Follower counts, hearts, checkmarks | Parasocial substitution; loyalty on a leaderboard |
| Governance | Flags, seals, ballots, checkboxes | Consent-theater; directed flooding |
| Energy | Battery icons, streaks, burnout scores, kWh | Emotional extraction; strain as the cost line |

## The pattern under all twelve

The glyph outlives the thing. A grade, a score, a code, a count — the mark keeps circulating and deciding long after the underlying function has hollowed out. The system no longer needs the thing it was built to track. It only needs the symbol.

That is why these twelve are the automation targets. A system that runs on symbols can be run by a machine that manipulates symbols. What gets automated is not the function — the function is already gone in most of them. What gets automated is the mark-making itself.
